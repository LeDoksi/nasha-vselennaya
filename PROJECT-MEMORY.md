## 4. Хранилище (localStorage)

| Ключ | Что хранит |
|---|---|
| `universe` | главный объект: `{ version, events, notes, shopping, todos, photos, dates, wishlist, labels, backupDate }` |
| `universe_vault` | зашифрованный сейф: `{ ver:1, db (AES-GCM), keys: [{ who, k, s, iter, iv, a }] }` |
| `universe_user` | кто сейчас у сайта: `'gosha'` или `'dasha'` |
| `universe_theme` | тема: `'light'` или `'dark'` |

- **Версия схемы:** `DB_VERSION = 5` в объекте `db`. Загрузка через `migrateDB()`:
  добавляет новые поля старым данным (wishlist, backupDate, labels, version,
  `order` заметок) и конвертирует старые альбомы фото в лейблы. Правь `migrateDB`,
  когда меняешь форму данных, — и старые данные переживут апдейт.
- **Лимит** ~5 МБ (localStorage). Фото сжимаются до jpeg 900px / качество 0.82.
- Копия — вручную: **Настройки → Скачать копию** (JSON); при экспорте ставится `db.backupDate`,
  и Настройки показывают, сколько времени прошло с последней копии. Облака пока нет.

### Формы данных
```js
events:   { id, title, date:'YYYY-MM-DD', emoji, repeat: bool,
            endDate:'YYYY-MM-DD'|null (долгие события, repeat принудительно false),
            photos:[dataURL]|undefined (фото события; дублируются в db.photos с лейблом = title) }
dates:    { id, date, time:'HH:MM', from:'gosha'|'dasha'|'both'|undefined(legacy),
            responses:{gosha:null|'yes'|'no', dasha:null|'yes'|'no'},
            place, note, emoji, done: bool }
notes:    { id, text, ts, pinned: bool, author:'gosha'|'dasha'|undefined(legacy),
```

- Порядок фото: `photoSort` — закреплённые сверху, дальше по `order` (по возрастанию).

## 5. Ключевые механики

### Вход, сейф и текущий пользователь
- Все данные — в **зашифрованном сейфе** `universe_vault`: общий AES-GCM ключ,
  обёрнутый (wrap) для каждого пароля (PBKDF2 → AES). Первый запуск мигрирует
  старый открытый `universe` в сейф и удаляет его.
- Разблокировка: `unlockWith(who, pass)`; смена/добавление пароля: `changePass` /
  `savePassFor`; замок `lock()` стирает ключ и данные из памяти.
- **Salt (PBKDF2) обязан храниться в wrap (`keys[].s`)** — был баг: без него после
  перезапуска сейф не открывался. AES-key при разблокировке **extractable** (`true`),
  иначе не сделать wrap для пароля партнёра.
- Текущий пользователь: `getUser()`/`setUser(u)`; чип в шапке `#userChip`.
- **Свидание/хотелка всегда от имени вошедшего** — селектов «кто» в модалках нет.

### Парящие фото на главной (hero)
- Обёртка `.hero-zone` вокруг `.hero-card`; внутри `#floatPhotos`.
- `FLOAT_SLOTS` — **5 «гнёзд»**, каждое = `{ st (CSS position), rot, dur, delay }`
  (стили зашиты прямо в слот). Несимметричны, в стороне от текста.
- `pickFloating()` — заполняет **3 случайных слота** из 5 тремя случайными фото
  (splice-алгоритм). Отдаёт массив из 5 элементов (null = пустой слот).
- При первом рендере — сразу одна заливка; дальше `setInterval(…, 7000)` сменяет
  фото **плавно** (opacity 0 → замена → 1, через 650ms).
- `pointer-events:none` — фото не мешают кликам. На экранах **≤820px скрыты**
  (медиа-запрос, чтобы не лезли на текст) — вместо них под главной горизонтальная
  лента `#mobilePhotosGrid` (`renderMobilePhotos()`, показывается только ≤820px).
- Эмодзи-декоры 💜/🌸 из hero убраны (их места заняли фото); ✨ оставлен.

### Свидания и ответы (важно!)
- Кнопка «💘 Назначить свидание» → модалка: дата, время, место, идея, эмодзи.
  «Дата» и «Во сколько» — в `.two-col .field` (label над полем, поля во всю
  ширину колонки — выровнены в одну линию).
  **Селекта «кто приглашает» нет** — свидание всегда от имени вошедшего
  (`from: getUser()` в `saveDateFromModal()`). Вариант «Вместе» не создаётся
  (старые свидания `from:'both'` рендерятся для совместимости).
- Пригласивший **уже согласен** — у него в статусе «💌 позвал/позвала», кнопок Да/Нет нет.
- Отвечает **только приглашённый**: `canAnswer = !from || from === 'both' || from !== who`.
- Если `from === 'both'` — отвечать могут оба.
- Ответ — переключатель: повторный клик снимает выбор (`resp[who] = val` → `null`).

### Прочее
- Календарь: события с `repeat` показываются каждый год; клик по дню → панель справа.
  События можно **редактировать** (кнопка ✏️ → `openEventModal(id)` с `editingEventId`).
- Главная: блок напоминаний «Скоро важное событие» **удалён** (дублировал таймер ⏳).
- Заметки: на карточке — **автор** (👦/👧, legacy без `author` → 💜 «Наши»),
  **✏️-правка** (кнопка `data-edit-note` или двойной клик → инлайн-текст с
  `data-save-note`/`data-cancel-note`), **drag&drop** (карточки `draggable`; на
  `drop` пересчитывается `order` всем заметкам). Сортировка: закреплённые сверху,
  дальше по `order`, в конце по времени. Закрепление/удаление — `togglePinNote()`/
  `deleteNote()` (может любой, без проверки автора). Добавление Ctrl+Enter.
- Списки: покупки 🛒 и дела ✅, счётчики «в работе».
- Фото: загрузка до 10 файлов за раз, лайтбокс, закрепление ⭐, **лейблы 🏷**:
  у фото несколько лейблов, фильтр сверху («Все фото» или один лейбл), выбор
  нескольких фото (кнопка ○ на карточке) и добавление лейбла сразу всем,
  удаление лейблов без вреда фото.
- Песня: `<audio>` грузит `music/nasha-pesnya.mp3`; если нет — подсказка.

### Витрина «📅 События» и удаление фото
- `renderEventBar()` вызывается из `renderPhotos()` (перед сеткой). Витрина видна,
  только когда `currentLabel === EVENT_LABEL`.
- Кнопки-уровни: `#eventYears` (годы, по убыванию), `#eventMonths` (месяцы
  выбранного года), `#eventTitles` (события выбранного месяца). Каждый уровень
  `display:none`, пока у него нет кнопок или не выбран родитель. На кнопках —
  счётчик фото: `eventPhotosCount(year, month, title)` считает уникальные фото из
  галереи, чьи события (`eventsForPhoto(data)`) подходят под фильтр.
- Один делегат клика на `document` обслуживает все уровни; повторный клик по
  активной кнопке сбрасывает этот уровень (и более глубокие); «✕ Сбросить»
  (`data-ev-reset`) сбрасывает весь `eventFilter`.
- `deletePhoto(id)`: удаляет из `db.photos` + вычищает dataURL из `ev.photos`
  всех событий (пустые массивы убирает) + `renderCalendar()` — удалённое фото не
  остаётся «мёртвой» миниатюрой в панели дня.

### Комплимент дня и таймер
- `renderCompliment()` — карточка под hero. Фраза выбирается **на весь день** по хэшу
  `toDateString()` (массив `COMPLIMENTS`, 20 штук) — при перезагрузке не прыгает.
- `renderCountdown()` — таймер до **ближайшего будущего** события/свидания
  (`nextTarget()` перебирает события и свидания, учитывая время свиданий).
  Тикает каждую секунду (`tickCountdown()` → `#countdownTick`). Если событий нет — скрыт.

### Тёмная тема
- Кнопка `#themeToggle` в шапке и `#settingsThemeBtn` в настройках → `toggleTheme()`.
- Значение в `localStorage['universe_theme']`, атрибут `data-theme` на `<html>`.
- В `styles.css` у `:root` базовые CSS-переменные; `[data-theme="dark"]` переопределяет
  палитру + точечные корректировки тёмных карточек.

### Хотелки (wishlist)
- Вкладка «Хотелки»; модалка `#wishOverlay`: **текст обязателен**, фото и ссылка — нет.
  **Селекта «для кого» нет** — хотелка всегда в список вошедшего (`owner: getUser()`
  в `saveWishFromModal()`).
- Вишлист **разделён по людям**: две секции «👦 Хотелки Гоши» и «👧 Хотелки Даши»
  (фильтр по `owner`, сортировка: невыполненные сверху). Секции «хочу подарить» нет —
  подарок это сюрприз, его не показываем в списке.
- `wishCard()` — карточка: фото (клик → лайтбокс через `data-photo`), ссылка (target=_blank),
  отметка «исполнено» ✅ (`data-wish-done`) и удаление.

### Конфетти
- `celebrate()` — 36 частиц 💜💖✨🎉🌸💞 падают через весь экран (класс `.confetti`).
- Срабатывает: (1) когда оба ответили «да» на свидание; (2) на главной, если сегодня
  событие (`rem.some(days===0)`) — **один раз в день** (флаг в sessionStorage).

### Настройки: бэкап и место
- `renderSettings()` — сколько занято в браузере (JSON размер) и сколько времени прошло
  с последней копии (`db.backupDate`). Если копии не было **30+ дней** — жёлтое
  предупреждение. Экспорт обновляет `backupDate`.

### Летающие сердечки
- `spawnHeart()` (💜💖💕🌸✨) теперь: раз в **3.8с**, **только на главной** и
  **пауза, пока открыта модалка** (`.overlay:not([hidden])`). Живут 12с.

      у сетки фото `dropEffect='move'`, у лейбла `dropEffect='copy'`.
